# Jira VOC Nexus

## 개요

`Jira VOC Nexus`는 사내 Jira에 접수되는 VOC를 기존 이슈, 프로젝트 위키, 관련 프로젝트 코드 지식과 연결해 triage와 조치 추천을 지원하는 봇 프로젝트다. 사내 인증과 접근 제어는 실행 환경이 담당하며, 저장소에는 인증 정보나 운영 비밀을 보관하지 않는다.

## 초기 목표 워크플로우

1. 새 Jira VOC 이슈를 수집하고 제목·본문·댓글·메타데이터를 검색 가능한 형태로 정규화한다.
2. 기존 이슈 RAG에서 의미적으로 유사한 이슈를 검색하고, 해결 상태·유사도·근거를 기준으로 후보를 재정렬한다.
3. 유사 이슈의 실제 조치사항과 결과를 바탕으로 새 이슈에 적용 가능한 추천 조치사항을 만든다.
4. 추천의 근거가 된 이슈와 조치 내역을 함께 표시해 검토 가능성을 확보한다.
5. Jira 댓글에 추천 조치사항을 추가하고, 분류 결과에 맞는 라벨을 부여한다.
6. 처리 결과와 사용자 피드백을 다시 색인해 라벨링·클러스터링·검색 품질을 개선한다.

## 연결할 지식 소스

- **Jira 이슈 RAG**: 과거 VOC, 유사 이슈, 해결 과정, 조치 결과
- **프로젝트 전반 지식 위키**: 업무 용어, 운영 절차, 시스템 정책, FAQ
- **관련 프로젝트 코드 그래프 RAG**: 서비스·모듈·API·테이블·소유 팀 간 관계와 코드 근거

세 소스는 독립적으로 검색하는 데 그치지 않고, 하나의 VOC를 중심으로 이슈·업무 지식·코드 영향 범위를 함께 설명할 수 있도록 연결한다.

## 최적화 방향

- VOC 도메인에 맞는 라벨 체계와 라벨 부여 기준 정립
- 중복·반복 VOC와 주제별 클러스터의 안정적인 식별
- 키워드 검색과 임베딩 검색을 결합한 하이브리드 검색 및 재정렬
- 해결된 이슈의 조치사항과 결과를 우선하는 추천 랭킹
- 추천 문장별 원문 이슈·위키·코드 근거와 신뢰도 기록
- 라벨·클러스터·추천 결과에 대한 사람의 수정 내용을 품질 피드백으로 활용
- 사내 데이터 권한 경계를 넘지 않는 검색·캐시·로그 설계

## MVP 범위

첫 단계는 다음 동작을 안정적으로 제공하는 데 둔다.

- 새 Jira VOC 수신
- 기존 이슈에서 유사 이슈 선정
- 해결 이슈의 조치사항 기반 추천 생성
- 추천 조치사항을 Jira 댓글로 추가
- 기본 라벨 부여
- 추천 근거와 처리 결과를 추적 가능한 형태로 기록

자동 이슈 종료, 무검토 배포, 코드 자동 수정, 권한 우회는 초기 범위에 포함하지 않는다.

## 운영 원칙

- 외부 노출이 불필요한 사내 지식은 저장소와 로그에 평문으로 복제하지 않는다.
- 모든 추천은 사람이 검토할 수 있는 근거와 함께 제공한다.
- 검색·라벨링·클러스터링 품질은 고정된 가정이 아니라 실제 처리 결과와 피드백으로 반복 개선한다.
- Jira 댓글과 라벨 변경은 재시도에 안전하고 중복 실행을 식별할 수 있어야 한다.

## 다음 설계 항목

- Jira 이벤트 수신 및 댓글·라벨 쓰기 경계
- 기존 이슈 RAG의 문서 스키마와 메타데이터
- 위키 및 코드 그래프의 동기화 주기·권한 필터
- 유사 이슈·추천 조치사항의 평가셋과 품질 지표
- 사람 검토 후 승인·수정·무시를 기록하는 피드백 루프
